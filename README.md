# raad-learning-journey

# رحلة مع آيات سورة الرعد

موقع تعليمي تفاعلي للآيات ٨–١٥، موجّه لطالبات الصف الأول الثانوي، بشرح مبسط مستند إلى تفسير السعدي.

يتضمن خمس مراحل، ومعاني كلمات داخل الآيات، ونشاط ترتيب، وخلاصة، واختبارًا من خمس أسئلة. تُحسب النتيجة من المحاولة الأولى مع السماح بإعادة المحاولة للتعلم.

## Usage

Open `index.html` in a browser. Keep `style.css` and `app.js` alongside it. No installation or build step is required. Google Fonts loads online, with system fonts as a fallback.

## GitHub Pages

In this repository, go to **Settings → Pages → Deploy from a branch**, select **main** and **/ (root)**, then **Save**. Uploading the source does not by itself enable GitHub Pages.

## Source

[تفسير السعدي — جامعة الملك سعود](https://quran.ksu.edu.sa/tafseer/saadi/sura13-aya8.html). Links for all eight verses are in the site footer. The explanations are educational summaries, not verbatim quotations.
